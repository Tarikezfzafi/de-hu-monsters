# de-hu-monsters

Next.js project voor Project 3.

## Vereist

- [Node.js](https://nodejs.org) 20.9 of hoger (check met `node -v`)
- Git

## Aan de slag

```bash
git clone https://github.com/Tarikezfzafi/de-hu-monsters.git
cd de-hu-monsters
npm install
npm run dev
```

Open http://localhost:3000.

## Commands

| Command | Doel |
|---|---|
| `npm run dev` | Start de ontwikkelserver |
| `npm run build` | Maak een productiebuild |
| `npm run lint` | Controleer de code |

## Afspraken

- Werk op een eigen branch, niet op `main`.
- Na een `git pull`: draai `npm install` als `package.json` veranderd is.
- Pagina's staan in `app/`. Een nieuwe map met `page.tsx` is een nieuwe route.
